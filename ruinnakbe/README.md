# ruinnakbe

A simple web application to get and display the current timestamp, and to upload and list files.

## Features

- Displays the current server timestamp.
- Allows users to upload files.
- Lists all uploaded files.

## How to run

1.  Clone the repository.
2.  Install the dependencies:

    ```bash
    pip3 install -r requirements.txt
    ```

3.  Run the application with the following command:

    ```bash
    python3 main.py
    ```

4.  Open your web browser and navigate to `http://127.0.0.1:8080` to see the application.

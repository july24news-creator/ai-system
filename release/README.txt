Noakhali AI System v0.3.1
=======================

This is a Linux executable for the Noakhali AI System.

To run the application, first extract the archive:

    tar -xzvf Noakhali-AI-System-v0.3.1-linux.tar.gz

Then, run the executable:

    ./Noakhali-AI-System/main

This will start a web server. Open your web browser and navigate to http://127.0.0.1:8080 to use the application.

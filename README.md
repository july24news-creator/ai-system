# ai-system

This project is provided free of charge and is intended to remain free to use.

Important notes
- No billing or paywall is included in this project by default.
- DISABLE_BILLING=true in .env ensures any optional billing integrations must be explicitly enabled by you.
- All included examples and code use open-source libraries only (FastAPI, Transformers, etc.). Some third-party libraries (like model weights) may reference external hosting (Hugging Face) — verify license of any model you use.
- If you wish to integrate a paid third-party API (text-to-speech, paid model hosting, analytics), do NOT commit secrets to this repo. Instead, configure such integrations in your private environment and set DISABLE_BILLING=false deliberately.
